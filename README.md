# Автосервис — демоверсия сайта

Демонстрационная версия одностраничного сайта автосервиса по адресу: **ул. Доватора, 21, Ростов-на-Дону**.

Сайт доступен по GitHub Pages: https://[ваш-никнейм].github.io/auto/

> **Важно:** Это демоверсия, сайт ещё не куплен и не выложен на основной домен. Используется исключительно в демонстрационных целях.

## Структура
- index.html — основная страница
- styles.css — тёмная тема, адаптив
- main.js — статус работы, меню, галерея, отзывы
- logo.jpg — логотип

## Запуск локально
Откройте index.html двойным кликом в браузере.

## Данные
Вся информация (цены, фото, отзывы, адрес, телефон) взята с карточки Яндекс Карт и сверена с первоисточником.
